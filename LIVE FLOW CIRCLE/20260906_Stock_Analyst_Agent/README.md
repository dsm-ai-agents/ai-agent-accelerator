# AI Portfolio Analyst — V1 & V2

This repository contains **two versions of the same AI Portfolio Analyst classroom project**.

Both versions demonstrate how Claude Cowork can coordinate multiple agents to review a portfolio of stocks, analyse market information, make a **Buy / Hold / Sell** decision, and update an Excel-based portfolio state.

The difference is mainly in **complexity, structure, and level of implementation detail**.

---

## Which Version Should I Use?

| Version | Best For | What It Focuses On |
|---|---|---|
| **V1** | First-time learners, classroom demos, understanding multi-agent architecture | Simple scaffolding, agent roles, analysis framework, scoring, and parallel agents |
| **V2** | Learners who want a more complete end-to-end implementation | API-based data collection, strict folder structure, reusable state, caching, guardrails, archiving, Excel updates, and dashboard generation |

---

# V1 — Simple Multi-Agent Portfolio Analyst

Go to:

```text
V1/
```

V1 is the **simpler learning version**.

Its purpose is to help you understand the basic idea of converting a stock-analysis workflow into a multi-agent system without adding too much infrastructure.

### What V1 demonstrates

- Creating a multi-agent project structure
- Defining five agent responsibilities
- Building an analysis framework before execution
- Technical analysis
- Fundamental analysis
- Sentiment / news analysis
- Running research agents in parallel
- Scoring individual parameters
- Combining scores into an overall decision
- Producing an Excel output with:
  - Actual analysis values
  - Parameter-level scores
  - Overall score
  - BUY / HOLD / SELL / NO ACTION
  - Sources
  - Previous review information

### V1 Agent Flow

```text
Agent 1
Create Analysis Framework
        |
        v
+-------------------------------+
| Agent 2 — Technical Analysis  |
| Agent 3 — Fundamental Analysis|
| Agent 4 — Sentiment Analysis  |
+-------------------------------+
        |
        v
Agent 5
Combine Scores + Final Decision
        |
        v
Excel Output
```

### Use V1 when

You want to understand **how agents are designed and orchestrated** before worrying about APIs, caching, file governance, dashboards, or production-style guardrails.

# V2 — Complete Stateful Portfolio Analyst

Go to:

```text
V2/
```

V2 takes the same idea and converts it into a **more structured, repeatable workflow**.

It introduces a defined folder architecture, an Alpha Vantage market-data workflow, API-call controls, cached data, a reusable Excel state file, archive rules, detailed agent activation steps, and an HTML dashboard.

### What V2 adds

- Alpha Vantage API integration
- API key handling
- Daily API-call budget controls
- Raw market-data caching
- Strict input / output / archive / dashboard folders
- Five clearly separated operational agents
- Previous-state reading
- Technical indicator calculation from cached data
- Fundamental assessment
- Auditable Buy / Hold / Sell decision logic
- Excel state updates between runs
- Formula protection
- File archiving instead of deletion
- Self-contained HTML dashboard
- Repeatable review workflow

### V2 Agent Flow

```text
Agent 01
Setup Check + Read Previous State
        |
        v
Agent 02
Fetch Market Data
        |
        v
Agent 03
Technical + Fundamental Analysis
        |
        v
Agent 04
Decision + Update Portfolio State
        |
        v
Agent 05
Save + Archive + Build Dashboard
```

### V2 Folder Structure

```text
V2/
├── 01_input/
├── 02_output/
├── 03_archive/
├── 04_dashboard/
├── agents/
└── CLAUDE.md
```

### Use V2 when

You already understand the basic multi-agent concept and want to see how the same idea becomes a **more disciplined end-to-end agent workflow**.

# Recommended Learning Path

If this is your first time building an agent workflow:

```text
Start with V1
    ↓
Understand the agents and scoring logic
    ↓
```

V1 teaches the **concept**.

V2 teaches the **implementation discipline**.
