# AI Portfolio Analyst

A multi-agent stock review system built in Claude Cowork. Five agents read your previous decisions, pull fresh prices, analyse, decide Buy/Hold/Sell, and write back to Excel.

**Classroom exercise. Not investment advice.**

## Step 1 — Scaffolding - Set up the folder

Create one empty folder on your computer. Call it `PortfolioAnalyst`. Select it in Claude Cowork.

Paste this prompt. Run it once.

```
Create a multi-agent stock analysis pipeline from a CSV or Excel file containing 10 stocks.

First create `CLAUDE.md` with:
- Project goal
- Workflow
- Folder structure
- Input file format
- Analysis framework
- Scoring logic
- Outputs
- Agent roles

Agents:
- `agent_1_framework.md` — read the stock file and create the analysis framework, required columns, parameters, scoring tables, and decision structure.
- `agent_2_technical.md` — research 3–5 technical parameters for every stock and return actual values, scores out of 10, and sources. This should be an Excel file. 
- `agent_3_fundamental.md` — research 3–5 fundamental parameters for every stock and return actual values, scores out of 10, and sources.
- `agent_4_sentiment.md` — research key sentiment/news parameters for every stock and return actual values, scores out of 10, and sources.
- `agent_5_decision.md` — combine all agent outputs, calculate overall scores, apply the decision rules, and update the final Excel output.

Research:
- Default to internet search.
- Agents 2, 3, and 4 should list sources used.
- Optionally ask whether the user wants to use a market/data API instead.
- If API is selected, request the required API details before using it.

Excel output should contain:
- Table 1: actual technical, fundamental, and sentiment values for each stock.
- Table 2: parameter-level scores out of 10.
- Overall score.
- BUY / HOLD / SELL / NO ACTION decision.
- Sources.
- Review date and previous decision fields for future runs.

Default decision logic:
- Score ≥ 7 → BUY
- Mid-range score → HOLD / NO ACTION
- Low score → SELL
- Keep scoring thresholds configurable.

Agents 2, 3, and 4 should run in parallel after Agent 1 creates the framework.

Before creating files, show:
- Proposed architecture
- Agent workflow
- Analysis parameters
- Scoring method
- Excel structure
- Outputs

Ask for approval.

Then create the project structure in the local folder.
```
