## Summary

This is NexaFlow's standard proposal template for Professional and Enterprise opportunities. It contains the required sections, guidance for each, and fill-in placeholders in square brackets. All prices must be taken from `pricing_guide_v3.md` and any discounts must be approved under `discount_policy.md` before a proposal is sent.

## Main Content

### Before You Start: Proposal Checklist

- [ ] Opportunity is at Stage 5 with MEDDPICC minimums met (`sales_playbook.md`)
- [ ] ROI numbers agreed with the champion
- [ ] Implementation track (Standard 4–6 weeks or Complex 8–12 weeks) confirmed with the implementation lead
- [ ] Prices taken from `pricing_guide_v3.md` (never from older price sheets or the v2 table in `pricing_faq.md`)
- [ ] Discount approval recorded in the CRM
- [ ] Relevant case study selected

### PROPOSAL TEMPLATE

**NexaFlow Proposal for [Customer Name]**
Prepared for: [Economic Buyer Name, Title]
Prepared by: [Account Executive Name]
Date: [Date] — Valid for 30 days

#### 1. Executive Summary

*Guidance: one page maximum. Written for the economic buyer. Lead with their outcome, not our features.*

[Customer Name] wants to [business goal, e.g., "reduce supplier onboarding time and manual procurement work across four plants"]. Today, [describe current process and pain in one or two sentences, using the customer's numbers].

NexaFlow will automate [number] priority workflows across [systems], using governed AI agents with full audit trails. Based on the figures agreed with your team, we expect [primary metric, e.g., "a 35% reduction in processing time"] and payback within [X] months.

#### 2. Understanding of Your Current Situation

*Guidance: prove we listened. Use discovery notes.*

- Process(es) in scope: [list]
- Volume: [transactions per month]
- Systems involved: [list]
- Key challenges: [3–5 bullet points with numbers]
- Why now: [trigger event]

#### 3. Proposed Solution

*Guidance: map each challenge to a NexaFlow capability. Avoid a full feature list.*

| Challenge | NexaFlow Solution | Module |
|---|---|---|
| [e.g., Manual re-keying from PDFs] | [AI document extraction agent] | Agent Studio |
| [e.g., Approvals lost in email] | [Approval routing in Teams] | Flow Builder |
| [e.g., No visibility] | [Real-time SLA dashboard] | Command Center |

Integrations: [list connectors; note premium connectors or Relay if needed]
Security and compliance requirements met: [SSO, SCIM, audit logs, data residency, BAA]

#### 4. Expected Business Outcomes and ROI

| Value Driver | Assumption | Annual Value |
|---|---|---|
| Hours saved | [hours/week] × 52 × $[loaded hourly cost] | $[amount] |
| Error reduction | [errors avoided] × $[cost per error] | $[amount] |
| Faster cycle time | [impact] | $[amount] |
| **Total annual value** | | **$[amount]** |

Payback period: [months]. Three-year ROI: [percentage].

Reference customer: [Case study name and headline metric, e.g., "ManufacturingCo Industries — 40% reduction in manual work"].

#### 5. Implementation Plan

*Guidance: use the implementation track confirmed with the implementation lead. Do not promise dates before discovery.*

| Phase | Timing |
|---|---|
| Discovery and requirements | Week [1] |
| Solution design | Weeks [1–2] |
| Environment setup | Week [2] |
| Integration configuration | Weeks [2–3] |
| Data migration | Weeks [3–4] |
| Testing | Weeks [4–5] |
| User training | Week [5] |

| Post-launch hypercare | 30 days after go-live |

Estimated go-live: [4–6 weeks / 8–12 weeks] after kickoff, subject to security review and stakeholder availability.

#### 6. Investment Summary

### Writing Tips

- Use the customer's language and numbers throughout.
- Keep the proposal under 10 pages; put detail in appendices.
- Never include internal price floors or approval notes.
- Send as PDF and walk through it live rather than emailing cold.

## Key Facts

- Proposals are valid for 30 days.
- Prices must come from `pricing_guide_v3.md`; discounts need prior approval.
- Proposals must include ROI, implementation plan, investment summary and next steps.
- Implementation plan follows the nine phases: 4–6 weeks standard, 8–12 weeks complex.
- Kickoff happens within 5 business days of signature.
